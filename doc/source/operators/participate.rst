Mailing List
=============
The OpenStack community, including operators, is using one unified mailing
list for discussions about the project and platform. By `joining the
mailing list
<https://lists.openstack.org/mailman3/lists/openstack-discuss.lists.openstack.org/>`_
you can connect with fellow operators and users, while also follow ongoing
discussions about the development of OpenStack.

.. note::
   To get more operator attention, prepend '[ops]' to your email subject lines.

More generic information about mailing lists can be found in the Communication
page's :ref:`communication-mailing-lists` section.

Matrix Room
===========
The OpenStack Operator community is currently utilizing Matrix as their chat
platform for more synchronous discussions, when possible.

If you already have a Matrix account, head to the `OpenStack Ops
<https://matrix.to/#/#openstack-ops:opendev.org>`_ Matrix room to chat with
fellow operators.

The OpenDev and Zuul communities also use Matrix for their daily chat, you
can find detailed documentation on how to create an account and start using
Matrix in the `Zuul documentation
<https://zuul-ci.org/docs/zuul/latest/howtos/matrix.html#>`_

If you are still in the old, and now unused, #openstack-operators channel on
OFTC IRC please join the above Matrix room instead.

However, OpenStack developer teams are still utilizing IRC to varying extent.
If you would like to get in touch with a project team on the chat platform,
please find some more generic information about IRC channels in the
:ref:`irc-channels` section of the IRC page.

In the :ref:`setup-irc` section of this guide, there are instructions on how
to set up a desktop client and register your irc nickname so that you can
join these channels.

.. _ops-radio-hour:

Ops Radio Hour
==============
This is a monthly call series in a casual setting for operators, engineers,
and contributors to come together, share knowledge, and collaborate on the
complexities of deploying and managing OpenStack environments.

- Cadence: Monthly, usually on the last Friday of the month
- Timing: Calls start at 1300 UTC
- Platform: Running on `Meetpad
  <https://meetpad.opendev.org/openstack_ops_radiohour>`_,
  which is a Jitsi instance maintained by the OpenDev community
- Agenda and Notes: Maintained in an `etherpad
  <https://etherpad.opendev.org/p/openstack_ops_radiohour>`_

.. _ops-meetup:

Meet Ups
========
`Operators' Meetups
<https://wiki.openstack.org/wiki/Operations/Meetups>`_ give people who run
clouds a place to congregate, swap best practices, ideas and give feedback.
It has a mostly round table/working/discussion session feel, with only a
small number of presentations, with the following aims:

1. Gather feedback on the issues that come up in running OpenStack and
   work to communicate this throughout the community
2. Create a forum in which to share best practices and architectures between
   interested parties
3. Increase constructive, proactive involvement from those running clouds

These meetups are organized and facilitated by volunteers among the
operators community. If you don't see one being planned, please feel welcomed
and encouraged to propose one on any of the above mentioned communication
channels.
